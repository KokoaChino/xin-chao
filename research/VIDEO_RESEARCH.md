## 去重与角色关联

757条来源记录按完整BV号合并，共719个不同投稿。相同BV的合作投稿保留两个官方账号的来源信息，页面只展示一部。脚本同时检查规范化标题，兼容不同空格、竖线或全半角；不删除语种和版本文字。本次未发现相同规范化标题对应不同BV的情况。

优先按标题中的角色段落、完整形态名、服装名关联。若标题没有明确名称，仅在已核实原页的视频标签与角色名精确对应时补收。比如“拍拍共鸣者丨这种小事也要我来！”的原页标签为“莫特斐”“鸣潮莫特斐”，可以明确关联；“小心饮食”不能因为包含“心”而关联到角色“心”。支持官方标签中“陆赫斯”与角色名“陆·赫斯”的中点差异。

## 页面实现

- 角色详情“影像”标签只显示该角色已核实的影片。
- 全部共鸣者大卡片下方增加“全部角色影像”入口，按类型分组并提供分类计数，可搜索角色与影片名，分类和搜索可叠加。
- 使用B站官方iframe；用户选择影片后才加载，`autoplay=0`，不解析或下载视频流。
- 切换分类、改变搜索或关闭窗口时卸载当前播放器，保留全屏和原站观看入口。
- 页面索引为 `public/data/videos.json`，首次打开影像栏目时读取。

## 维护

浏览器检查两个账号的新投稿，补入对应原始摘要。标题不能确定归属的角色影片，查看原页标签并补入 `video-role-evidence.json`。然后运行：

```sh
npm run prepare:videos
npm test
npm run build
```

新增视频类型需要审阅分类规则。目录合并保留来源、去重并验证所有角色名称；不把B站目录描述为已实现全自动抓取。
