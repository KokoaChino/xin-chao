# 鸣潮角色素材质量抽查

核验日期：2026-10-23，Asia/Shanghai。

本文件仅记录素材与技术核验；没有实现最终 H5 页面。共完整下载解码与目视抽查 12 张图片：首批 7 张覆盖今汐、坎特蕾拉、漂泊者·气动及三个官方图片路径，补充 5 张 Wiki 高清编队图覆盖今汐、琳奈、丽贝卡和男女漂泊者。结论来自真实 GET、PNG 解码与真实浏览器显示，不只依据图片 URL 或文件后缀。

## 可直接采用的结论

- 排行榜的大头像优先采用库街区 `newHead/aki` 原图。今汐实测为 500×500；带 `x-oss-process=image/resize,w_128,h_128` 的版本只有 128×128。在同为 224 CSS px 的对比页上，原图的眼睛、发丝和饰品线条清楚，128 版明显模糊。
- 攻略站卡片图是 256×256，适合小尺寸列表头像。Wiki 当前头像样本也是 256×256，但人物周围留白较多，实际人物比相同显示尺寸的攻略卡片小。
- 攻略站立绘样本均为 696×960 透明 PNG；今汐与坎特蕾拉是半身裁切，底部和侧边已有透明渐隐。适合详情卡、榜首装饰或中小型人物展示；不能当作完整全身立绘。
- Wiki 编队立绘提供了更适合完整形象展示的大图：实测今汐 1111×1515、琳奈 1920×2843、丽贝卡 4285×6685、男女漂泊者各 1129×1654。补充抽查确认它们是独立全身透明图，服装、发丝、配饰等细节可辨；不是只读取到了更大的尺寸数字。
- 立绘可以在暗色或浅色背景上叠放，透明通道真实有效。在棋盘背景实际显示时边缘与渐隐正常；直接图片查看器对透明区的显示可能出现杂色错觉，不应据此判断源图损坏。
- 漂泊者·气动的攻略立绘是男女同框，Wiki 已补齐男女独立全身图；如果按性别排名，应优先采用 Wiki 独立图。是否再分属性排名仍需要产品层确认。
- 12 张图在第三方本地页面中均可直接显示，HTTP 响应均允许跨域。首批 7 张设定 `crossOrigin="anonymous"` 后均成功绘入 Canvas 并导出 PNG；新增 5 张没有逐张重复 Canvas 导出。此次抽查没有发现防盗链或已测图片的 Canvas 污染。

在同宽 220 CSS px 的检查页上，今汐、琳奈和丽贝卡占据容器较充分；男女漂泊者明显偏小。原因是男女漂泊者分别约 86.55% / 83.85% 的画布像素完全透明，而非图片质量低。页面应依据焦点和 alpha 边界统一视觉大小。

更大的全身画布不自动代表脸部更清楚。攻略站半身图与 Wiki 全身图包含的身体范围不同，适用于不同构图。全身主视觉优先 Wiki；小头像优先专门的原始头像；上半身特写仍应根据对应脸部的实际像素与最终裁切效果选择。

今汐这张全身图可在不超出 2x 源像素需求的约 555×757 CSS px 内使用；琳奈和丽贝卡对常规 H5 人物展示有更大余量。丽贝卡原图约 8.7 MiB，不建议对所有列表项首屏直接加载这一尺寸；清单应保留原始 URL，并按展示用途选择官方缩放 URL 或懒加载。

## 尺寸、透明边距与建议用途

“有效边界”是 PNG 中 alpha > 0 的像素包围盒，不等同于人物脸部边界；数值采用 `[left, top, right, bottom)`。

| 样本 | 原始尺寸 | 有效边界 | 完全透明像素 | 保守建议 |
| --- | --- | --- | --- | --- |
| 今汐 `newHead` 原头像 | 500×500 | `[0,14,500,500]` | 21.73% | 约 250 CSS px 内的头像可覆盖 2x 像素需求；常见 64–160 px 列表/榜单头像有余量 |
| 今汐 `newHead` 128 缩略版 | 128×128 | `[0,3,128,128]` | 19.19% | 2x 屏幕仅建议约 64 CSS px；大卡片应替换为原图 |
| 今汐 Wiki 头像 | 256×256 | `[8,34,232,232]` | 54.12% | 小型头像后备源；需处理额外透明留白，避免人物显小 |
| 今汐攻略卡片 | 256×256 | `[0,24,256,256]` | 31.89% | 约 128 CSS px 内覆盖 2x 需求 |
| 今汐攻略立绘 | 696×960 | `[0,169,696,957]` | 54.97% | 顶部 169 px 留空；约 348×480 CSS px 内覆盖 2x 需求 |
| 坎特蕾拉攻略立绘 | 696×960 | `[0,149,696,957]` | 45.99% | 顶部 149 px 留空；约 348×480 CSS px 内覆盖 2x 需求 |
| 漂泊者·气动攻略立绘 | 696×960 | `[0,42,696,960]` | 44.87% | 男女同框，底部硬裁切；约 348×480 CSS px 内覆盖 2x 需求 |

以上是避免源像素不足的保守展示尺寸，并非主观清晰度保证。若设计需要 450–600 CSS px 宽的主视觉或 3x 屏幕大幅展示，应优先评估前一节已找到的 Wiki 高清编队立绘。移除缩放参数只有在原 URL 存在图像处理参数时才有意义；已取得的攻略站立绘 URL 没有这种缩放参数，不能通过简单放大参数增加真实细节。

## 外链与导出验证

检测页 Origin：`http://127.0.0.1:8769`。

1. `curl` 使用第三方 `Origin` 与 `Referer` 请求原始图片，7 次均返回 HTTP 200，`Content-Type: image/png`。
2. 两类 CDN 的这 7 张图片均返回 `Access-Control-Allow-Origin: *`。
3. 真实 IAB 浏览器使用普通 `<img>` 从原始官方 URL 加载，7 张均 `decode()` 成功，`naturalWidth` / `naturalHeight` 与本地解码相同。
4. 再创建设置了 `crossOrigin = "anonymous"` 的图片，待其加载成功后调用 `drawImage()` 与 `toDataURL("image/png")`，7 张均导出成功。
5. 在浏览器中实际查看 224 CSS px 的头像与 348 CSS px 宽的立绘，核验清晰度、半身裁切与透明边缘。
6. 新增的 5 张高清编队图也均 HTTP 200、`Access-Control-Allow-Origin: *`，并在同一第三方页面正常显示。对丽贝卡另开 100% 源像素细节窗口；没有为这 5 张重复 Canvas 导出。

这是 2026-10-23 的抽样结果，不能推断整个 CDN 的全部文件始终拥有相同响应头。后续若加入新的域名或素材类型，应沿用同样验证。实现导出时需在赋值 `src` 前设置 `crossOrigin`，普通图片能显示本身不代表可以导出。

## 后续素材映射建议

- 素材清单分别记录 `avatarUrl`、`portraitUrl`、`width`、`height`、`alphaBounds`、`sourceUrl` 与角色识别信息，页面按 URL 索引，不把图片编码进组件。
- 头像原图与立绘的构图不同，应独立配置焦点、缩放比例或容器定位；只统一 `object-fit` 会让 Wiki 头像显小，也会让立绘头顶出现不一致空隙。
- 建议将半身、全身、男女同框等构图类型写入素材元数据，避免后续无意把“有图”视为“适合当前展示”。
- 500×500 原头像约 399 KiB，128×128 版本约 36 KiB；主视觉可用原图，较多隐藏/非首屏头像应延迟加载。具体首屏预算留到页面布局确定后处理。
- 本地下载仅用于解码与目视核验，位于临时目录。最终页面继续引用官方 URL。
